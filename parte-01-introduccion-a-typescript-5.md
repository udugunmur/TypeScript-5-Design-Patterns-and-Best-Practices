# Parte 1: Introducción a TypeScript 5

En esta sección, presentamos **TypeScript 5**, la versión más reciente de este potente lenguaje que amplía JavaScript añadiendo tipos estáticos. Exploraremos conceptos clave como la relación de TypeScript con JavaScript, las últimas características introducidas en la versión 5 y los beneficios del desarrollo guiado por tipos.

También aprenderás sobre herramientas de desarrollo como **VSCode** y herramientas de diagramación como **UML**, siendo ambas fundamentales para el desarrollo moderno con TypeScript. Al finalizar esta sección, contarás con las habilidades esenciales necesarias para desarrollar aplicaciones en TypeScript con total confianza.

- **Capítulo 2:** Principios fundamentales de TypeScript
